# RevenueGuard AI 🛡️

**What it does:** RevenueGuard AI is an autonomous AI-powered revenue recovery dashboard for Razorpay merchants that intercepts failed payment webhooks, diagnoses failure causes, and automatically recovers lost sales via intelligent WhatsApp, UPI, and card retry workflows.

**Tech Stack:** React 19, TypeScript, Vite, Tailwind CSS, Recharts, Lucide React, Canvas Confetti.

**How to run it:** Run `npm install` followed by `npm run dev`, then open `http://localhost:5173` in your browser.
